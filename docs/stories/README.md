## Status

Milestone 1 — **spec + generator + a Go SDK at wire parity** — is underway. R-1 froze the
`babelforce.v1` wire fixtures, R-2 established the model workspace and imported Go SDK, R-3 modeled
the complete typed catalog, and R-4 proved all 29 existing fixtures byte-identical through concrete
spec types. The 2026-08-03 soundness review is scheduled as R-17 (missing authority/variants) and
R-18 (semantic constraints); R-5 and R-8 remain independently ready behind those priorities.

The through-line: capture today's bytes as frozen fixtures (R-1), make the spec reproduce them
exactly (R-4), then generate everything else — types, envelope codec, role dispatch, docs, test
vectors — and prove it against those fixtures and against a live `rtvbp-go v0.37` peer.

Pillars: **Spec** (source of truth) · **Generator** (emitters) · **SDK** (hand-written runtimes) ·
**Proof** (fixtures, conformance, interop, CI).

No gate exists yet — establishing it is R-16.
