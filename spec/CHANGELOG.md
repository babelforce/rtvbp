# Protocol changelog

This changelog versions immutable distributions of the protocol specification. A snapshot version
does not change the frozen `babelforce.v1` wire catalog.

## [1.1.0] - 2026-10-23

### Added

- Added `spec/ess/`, an ESS specification of the `babelforce.v1` catalog generated by
  `rtvbp-spec-gen --emit=ess`, so consumers can compose their copy of the wire types against it.
  The generator refuses wire names, field names and descriptions that YAML would misread.
- Added the generated transport profile registry `spec/manifests/rtvbp.profiles.json` and the
  negotiation conformance profile `conformance/profiles/negotiation.json`.
- The `babelforce.v1` and `demo.v1` wire catalogs are unchanged.

## [1.0.0] - 2026-08-14

### Added

- Published the first self-contained RTVBP protocol snapshot with the frozen `babelforce.v1`
  catalog, its `classic.v1` envelope, source-pinned golden authority, generated conformance vectors,
  and executable scenarios.
- Included the additive `demo.v1` catalog as the proof that generation, negotiation, documentation,
  and conformance are catalog-agnostic.
