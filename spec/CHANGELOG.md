# Protocol changelog

This changelog versions immutable distributions of the protocol specification. A snapshot version
does not change the frozen `babelforce.v1` wire catalog.

## [1.0.0] - 2026-08-14

### Added

- Published the first self-contained RTVBP protocol snapshot with the frozen `babelforce.v1`
  catalog, its `classic.v1` envelope, source-pinned golden authority, generated conformance vectors,
  and executable scenarios.
- Included the additive `demo.v1` catalog as the proof that generation, negotiation, documentation,
  and conformance are catalog-agnostic.
