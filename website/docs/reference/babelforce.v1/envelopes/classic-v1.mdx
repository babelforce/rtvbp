## Errors

The error code space accepts **any non-zero integer**. These values are conventions minted by the deployed implementation:

| Name | Code | Description |
| --- | --- | --- |
| `unknown` | `-1` | Unclassified failure. |
| `bad_request` | `400` | The request is invalid. |
| `internal_server_error` | `500` | The handler failed internally. |
| `not_implemented` | `501` | The requested operation is not implemented. |

Error objects use `code`, `message`, and the optional `any` data field.

For frozen compatibility, a response may contain both `result` and `error`, or neither field. When both are present, the error determines the semantic outcome.
