The **voice** peer implements operations directed to it, may call operations implemented by its peer, emits its own events, and receives peer events.

## Must implement

- [`application.move`](../operations/application.move.mdx) — Advance the IVR flow to another application node after replying.
- [`audio.buffer.clear`](../operations/audio.buffer.clear.mdx) — Discard buffered audio that has not yet been played.
- [`call.hangup`](../operations/call.hangup.mdx) — Hang up the telephony call after replying.
- [`ping`](../operations/ping.mdx) — Measure application-layer latency and optionally echo arbitrary data.
- [`recording.start`](../operations/recording.start.mdx) — Start recording the telephony call.
- [`recording.stop`](../operations/recording.stop.mdx) — Stop a recording by identifier.
- [`session.get`](../operations/session.get.mdx) — Get selected session variables, or all variables when keys is empty.
- [`session.set`](../operations/session.set.mdx) — Set free-form variables on the voice session.

## May call

- [`ping`](../operations/ping.mdx) — Measure application-layer latency and optionally echo arbitrary data.
- [`session.initialize`](../operations/session.initialize.mdx) — Negotiate the audio codec and initialize a real-time voice session.
- [`session.terminate`](../operations/session.terminate.mdx) — Terminate the real-time voice session after replying.

## Emits

- [`audio.info`](../events/audio.info.mdx) — Report periodic audio read and write throughput counters.
- [`call.hangup`](../events/call.hangup.mdx) — Report that the telephony call has ended.
- [`dtmf`](../events/dtmf.mdx) — Report a DTMF key after the remote caller releases it.
- [`session.updated`](../events/session.updated.mdx) — Report a change to negotiated session state such as the selected codec.

## Receives

- [`agent.tool.call`](../events/agent.tool.call.mdx) — Publish the redaction-safe name of a tool invoked by the agent.
- [`audio.speech.started`](../events/audio.speech.started.mdx) — Signal that speech started for barge-in handling.
- [`input.transcript`](../events/input.transcript.mdx) — Publish one finalized caller speech transcript.
- [`output.transcript.delta`](../events/output.transcript.delta.mdx) — Stream an incremental piece of the agent's spoken-output transcript.
- [`output.transcript.done`](../events/output.transcript.done.mdx) — Finalize the current agent spoken-output transcript.
