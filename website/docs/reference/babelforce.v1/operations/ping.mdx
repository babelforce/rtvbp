Measure application-layer latency and optionally echo arbitrary data.

## Parameters

| Field | Type | Presence | Constraints | Description |
| --- | --- | --- | --- | --- |
| `t0` | `integer` | required | non-zero | Sender timestamp in epoch milliseconds. |
| `rtt` | `integer` | optional | — | Optional round-trip time measured by a previous ping. |
| `data` | `any` | optional | — | Optional arbitrary data echoed by the peer. |

## Result

| Field | Type | Presence | Constraints | Description |
| --- | --- | --- | --- | --- |
| `t0` | `integer` | required | non-zero | Echo of the request sender timestamp. |
| `t1` | `integer` | required | non-zero | Transport receive timestamp in epoch milliseconds. |
| `t2` | `integer` | required | non-zero | Application handling timestamp in epoch milliseconds. |
| `owd` | `integer` | required | — | Estimated one-way delay in milliseconds. |
| `data` | `any` | optional | — | Optional arbitrary data echoed from the request. |
