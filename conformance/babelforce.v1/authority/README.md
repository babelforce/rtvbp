# Go encoding authority

`go-float64-boundaries.json` is generated by the source-pinned
[`rtvbp-go v0.40.0` capture](../../tools/capture-rtvbp-go-v0.40.0/). It records exact
`encoding/json` scalar spellings by `float64` bit pattern, including values Go rejects. Regenerate
it with `go run .` from that capture directory; do not edit it by hand.

The Rust compatibility test consumes this authority for `AudioInfoItem.bytes_per_second`. The exact
supported deployed-rate envelope is positive zero or a finite non-negative value in
`1e-5..=2^53`. The capture also records representative outside values: notation differs below
`1e-5` specifically when `1e-6 <= value < 1e-5`, Go can choose shorter rounded integers above
`2^53`, negative zero loses its sign in the Rust adapter, and Go rejects non-finite values that
serde_json writes as `null`. A few disconnected outside values, including `1e-7` and the next
`float64` above `2^53`, happen to match today; they are witnesses, not compatibility commitments.

This file is boundary authority rather than a protocol payload fixture, so it is intentionally
outside the frozen golden fixture inventory.
